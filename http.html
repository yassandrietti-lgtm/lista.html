Protocolo HTTP

O que é o HTTP?

Protocolo de Transferência de Hipertexto é a base para toda a troca de dados na internet visual que acessamos pelo navegador.

HTTP na comunicação entre navegador e servidor

A comunicação tem início pelo navegador quando digitado um endereço, acesso em um link ou enviado um formulário.

Cliente e Servidor

Cliente é o navegador que envia uma solicitação ao servidor.

Servidor recebe essa solicitação, processa o pedido e envia uma resposta ao navegador.

Requisição e Resposta

Requisição é a mensagem que o navegador envia ao servidor, solicitando alguma informação ou recurso.

Resposta é a mensagem que o servidor devolve ao navegador, informando o resultado da solicitação.

Métodos GET e POST

GET Método utilizado para solicitar informações ao servidor.

POST Método utilizado para enviar dados ao servidor, como informações de um formulário.

Exemplo de uma requisição HTTP

Requisição utilizando GET

GET /index.html HTTP/1.1
Host: www.exemplo.com
Accept: text/html

Exemplo de uma resposta HTTP

Resposta do servidor

HTTP/1.1 200 OK
Content-Type: text/html
Content-Length: 125


    
        
Bem-vindo ao site!

Códigos de status HTTP

200 OK

Indica que a solicitação foi realizada com sucesso.

301 Moved Permanently

Indica que a página foi movida permanentemente para outro endereço.

302 Found

Indica que a página está temporariamente em outro endereço.

400 Bad Request

Indica que o servidor não conseguiu entender a solicitação enviada pelo cliente.

403 Forbidden

Indica que o servidor entendeu a solicitação, mas não permite o acesso ao recurso.

404 Not Found

Indica que o recurso solicitado não foi encontrado no servidor.

500 Internal Server Error

Indica que ocorreu um erro interno no servidor ao processar a solicitação.
